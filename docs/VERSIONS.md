## Version notes

- **Browser extension (Chromium)** (`extension`): The packaged zip strips the development key; the Chrome Web Store ID will differ from the unpacked ID. 1.5.0 adds portable rules: Settings → Move your rules exports the person's five hand lists as a versioned JSON file and imports one add-only, so a more permissive file can never undo a stricter browser. A running lock withholds additions to the allowlist and corrections and applies blocks and words. No permission, network path or storage field changed; 1.4.0's quiet UI and 1.3.0's language-aware scoring are retained.
- **Mac** (`macos`): Every target must carry the same MARKETING_VERSION and CURRENT_PROJECT_VERSION; 1.1.8 adds an on-demand breathing pause to the Mac app, reachable from Overview, the menu bar and ⇧⌘P. It records only a local day and count, changes no rule or protection layer, and keeps the 1.1.7 protection-authority and lock controls. Unsigned/unnotarized.
- **iPhone & iPad** (`ios`): The app, six Safari blockers and HisnActivityMonitor share one version set. 1.3.0 adds an on-demand pause (breath, reminder, needs and a local day/count tally), a calmer protection hero on the overview and daily quiet hours; the 1.2.0 freeze of the saved site and app-limit rules is retained. Seed v5 still supplies the 239,885-domain Safari list.
- **Android** (`android`): versionCode is monotonic and must increase for every uploaded or side-loaded update. 26 (1.0.0) adds per-app daily foreground-time limits alongside the protection lock, removal guard, managed lockdown, watchdog and bundled-list warning. Release APKs are checked; the release keystore is in the gitignored keys/android and must be backed up offline in two places. The Play AAB is built but not uploaded.

## Bumping a version

1. Bump the platform's own manifest: `extension/manifest.json`,
   `android/app/build.gradle`, or the Xcode target's `MARKETING_VERSION` and
   `CURRENT_PROJECT_VERSION`.
2. Change the same value in `versions.json` and update its `updated` date.
3. Run `python3 script/versions.py` to regenerate this page, then
   `python3 script/versions.py --check` (also part of `./test.sh python`).
4. Add the release notes to `CHANGELOG.md`. A version bump without a changelog
   entry is an unfinished release.

Android `versionCode` only ever increases. iOS and macOS build numbers only
ever increase for a shipped build. The extension version must match the
packaged zip name; the store assigns its own extension ID, not a version.
