Person blur

An optional viewing preference, separate from adult-content classification. Face-based predictions can be wrong or miss people.

Blur preference

Visual preferences save automatically. Matching media is blurred as a whole; detection currently uses visible faces, not full bodies.

These choices affect person protection, not adult-media blocking. Face-only is experimental for supported still images. Videos and unsupported image layouts fall back to whole-media protection.

During a commitment you can strengthen these settings, but cannot turn them off or reduce them.

Where visual checks work

Runs on permitted web pages, including changing feeds. Set Hisn's site access to all sites in your browser's extension settings. Browser settings pages are not scannable.
