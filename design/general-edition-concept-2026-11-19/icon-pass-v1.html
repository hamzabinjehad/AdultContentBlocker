3D icon pass: one icon style across the app

Today every row and tool uses flat Material icons. This replaces them with one set of black-and-gold 3D icons (3dicons, free to use) on soft coloured tiles, the same style as the new "What it costs you" page. Layouts, text and features stay the same; only the pictures and setup's answer buttons change. Small shots under each phone show how it looks now.

What changes

About 25 icons across Today, Shield, Your apps, Permissions, Tools and help, empty states and setup's answer cards. One style everywhere: black and gold on soft tiles.

What stays

Every feature, every layout, the text (only the longest lines get shorter) and the bottom bar. Dark mode keeps the same tiles, which read well on dark cards.

Cost

About 250 KB added to the app. The icons are CC0 (public domain) and credited in the licences screen.
